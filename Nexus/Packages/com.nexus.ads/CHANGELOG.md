# Changelog

The changelog of the ad package family: `com.nexus.ads` (core, Unity layer, editor), the provider
packages (`com.nexus.ads.levelplay`, `com.nexus.ads.max`, `com.nexus.ads.admob` once it moves to this
core) and `com.nexus.ads.bridge.nexus`. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
`package.json` is the released version, everything newer is under Unreleased. The plan is
[issue #8](https://github.com/CevatAYDN/GameContainer/issues/8).

## [Unreleased]

### Added
- **Engine-free core** `Nexus.Ads.Core` (`Runtime/Core`, `noEngineReferences: true`, no reference to Unity or `com.nexus.core`; issue #10): `AdPlacement`, the only-tightenable `AdPolicy` floors (gap, first-show delay, gap after rewarded, per-session and per-day caps, session resume gap), `PolicyGuard` with the 13 rule ids of `PolicyRules` (`UnknownPlacement` blocks an undeclared or wrongly typed placement name), `SessionTracker` (session reset after the resume gap, per-day counters in `IPacingStore`), `AdController` (consent first, one preloaded ad per used format, reload after every show, `RetryPolicy` back-off 2/4/8…64 s paused while hidden, reward delivered once and only on the SDK's reward callback, kill switch and ad-free entitlement answer NotReady without a violation, remote configuration only tightens), `ProviderGate` (editor = simulator; release build refuses test mode, test devices and sample units; development build needs test mode or published test data and runs the simulator on an unlisted device), `MediationLock` (one mediation per process, the simulator exempt), the scenario-driven `SimulatorProvider` (no fill, load failure, show failure, closed early, slow load, consent refused; interactive for an overlay), and the ports the host implements (`IAdProvider`, `IConsentFlow`, `IAdFreeEntitlement`, `IAdsRemoteConfig`, `IAdClock`, `IAppVisibility`, `IMainThread`, `IAdScheduler`, `IPacingStore`, `IAdTelemetry`). Proven by the host harness suite `AdsCoreSuite` (81 checks, run by the pre-commit hook), which also scans the core sources for engine references.
- **Unity layer** `Nexus.Ads.Unity` (`Runtime/Unity`; issue #10): `AdsSettings` asset with Test and Release tabs (editor and development builds read Test, release builds read Release; the mapping is fixed), the shared test device list, placements, policy floors and privacy flags; `ProviderStatusResolver`, the only place that computes NotInstalled / Inactive / TestOnly / Active / Invalid per platform; `AdsBootstrap` (settings → build kind → advertising id off the main thread → gate → registered provider or simulator → controller; pauses audio and time between open and close); the static `Ads` facade for projects without Nexus; `SimulatorOverlay` (IMGUI full-screen fake ad with reward, close and fail buttons); `AdRewardedButton` (visible only while its placement can show, pays once); the port implementations (`UnityAdClock`, `UnityAppVisibility`, `UnityMainThread`, `UnityAdScheduler` on unscaled time, `PlayerPrefsPacingStore`, `UnityAdTelemetry` fan-out). EditMode tests (13) lock the settings mapping, the derived required fields, the floor clamp and the resolver's five statuses; PlayMode tests (4) lock the editor simulator path with the pause, the first-minute interstitial block, the unscaled scheduler and the button.
- **Policy register and platform catalog** (Phase 1, issue #9): `docs/POLICY_COMPLIANCE.md` (+ `_TR.md`) maps every platform's official policy pages, read 2026-10-24, to a `PolicyRules` id, a validator check or a developer checklist item and records Google's Families self-certified status per network; `Editor/PlatformCatalog.json` carries the registration and documentation links, Google's sample ids with their source, the UPM package names, registries and defines of the LevelPlay, MAX and AdMob SDKs, and the setup steps in English and Turkish.
